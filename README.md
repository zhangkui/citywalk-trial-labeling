# CityWalk

城市漫步与文化导览平台。

## 技术栈

- Go 1.22 + net/http + MySQL + Redis
- Vue 3 + TypeScript + Vite + Pinia + Vue Router
- Docker + Docker Compose + Nginx

## 启动

```bash
docker compose up --build
```

访问：`http://localhost:8080`

默认管理员：`admin / Admin123!`

## 文档

- API 文档：`docs/API.md`
- 环境变量：`.env.example`
